# LendX Roadmap

This roadmap outlines the journey of LendX from a Testnet prototype to a production-grade autonomous lending engine on Stellar.

## 🟢 Phase 1: Foundation (Current)
*Focus: Core protocol mechanics and initial agent behavior.*

- [x] **Soroban Contract Suite**: Implement basic vault, lending, and borrowing logic.
- [x] **Dutch Auction Logic**: Borrower-protective liquidation auctions.
- [x] **Initial Agent Primitives**: Basic Monitor and Bidder agents using Action Model Programming.
- [x] **Frontend Dashboard**: View health factors and manage positions on Stellar Testnet.

## 🟡 Phase 2: Autonomous Economic Agents (Next 30 Days)
*Focus: Integrating x402 and self-sustaining agent loops.*

- [ ] **x402 Integration**: Implement atomic trigger fees for monitor agents.
- [ ] **Agent Wallet Auto-Refill**: Agents automatically use earned fees to top up XLM for gas.
- [ ] **Enhanced Oracle Support**: Integrate with Band/Redstone for robust price feeds on Soroban.
- [ ] **Liquidation Analytics**: Dashboard for tracking auction efficiency and surplus returned to borrowers.

## 🟠 Phase 3: Risk & Scale (Next 90 Days)
*Focus: Security, multi-asset support, and protocol stability.*

- [ ] **Multi-Collateral Support**: Support for yXLM and other Stellar-native assets.
- [ ] **External Security Audit**: Third-party review of Soroban contracts.
- [ ] **Dynamic Interest Rate Model**: Supply/Demand based interest rates.
- [ ] **Advanced Agent Strategies**: More sophisticated bidding logic for bidder agents to ensure market efficiency.

## 🔴 Phase 4: Mainnet & Governance
*Focus: Production launch and community ownership.*

- [ ] **Mainnet Deployment**: Live on Stellar Mainnet.
- [ ] **LendX DAO**: Decentralized governance for protocol parameters (LTV, Liquidation thresholds).
- [ ] **Institutional Partnerships**: Onboarding liquidity providers to the agent ecosystem.

---

*Note: This roadmap is subject to change based on community feedback and Stellar ecosystem developments.*
